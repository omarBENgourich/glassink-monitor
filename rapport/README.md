# GlassInk Monitor - rapport de PFA

Rapport en français réalisé pour :

- **Étudiant :** Omar Bengourich
- **Établissement :** École Nationale des Sciences Appliquées de Kénitra
- **Filière :** Réseaux et Systèmes de Communication
- **Option :** Systèmes ubiquitaires
- **Organisme d'accueil :** Saint-Gobain Sekurit Maroc

## Compiler

```bash
cd rapport
make pdf
```

Le résultat final est écrit dans :

```text
build/GlassInk-Monitor-Rapport-PFA.pdf
```

## Organisation

```text
rapport.tex          document principal, couverture et pages liminaires
chapters/            un fichier par chapitre
figures/selected/    photographies industrielles retenues
figures/screenshots/ captures des interfaces du prototype
assets/              logos et icônes de la pile technique
build/               PDF final
```

Les photographies, schémas, captures d'interface et icônes nécessaires à la
compilation sont conservés dans les dossiers `figures/` et `assets/`.
